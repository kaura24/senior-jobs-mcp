노인일자리 공개 MCP PoC

인증 없이 사용하는 읽기 전용, 부분 데이터 실험입니다.

현재 저장 건수와 상세 수집 범위는 MCP 도구 응답에서 확인할 수 있습니다.

원천 관찰 시각과 갱신 성공·실패 상태는 각 도구 응답에 표시합니다.
조회할 때 한국 날짜의 접수 기간과 저장된 원문 “접수중”을 함께 확인합니다. 설정된 갱신 경로가 원본 상태를 재검증하며, 미확인 공고와 전국 전체 커버리지는 구분해서 표시합니다.

MCP 서버 주소: /api/mcp (JSON-RPC POST)

  • describe_search_options: 저장된 검색 선택지와 누락 항목
  • search_jobs: 공고 검색과 페이지 조회
  • get_job_details: 저장된 공고와 캐시 요약 조회

전국 전체 수집 결과가 아닙니다. 상세 미수집 범위는 응답의 실제 건수로 표시합니다. 나이·급여·근무시간·자격 정보가 없으면 확인이 필요한 것으로 안내합니다. MCP 조회는 저장된 스냅샷을 사용합니다. 별도 인증된 갱신 경로의 설정·실행 여부는 도구 응답의 갱신 상태로 확인합니다.
