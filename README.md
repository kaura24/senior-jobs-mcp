# Senior jobs MCP

기본 조회와 자동갱신 기능을 하나의 비공개 프로젝트에서 관리합니다. 최신 소스는 운영 MCP 1.3.0이며 기본 MCP 1.1.1은 `basic-mcp-v1.1.1` 태그와 Git 이력으로 보존합니다. 같은 코드의 별도 복제 디렉터리를 두지 않습니다.

## 조회 도구

운영 주소: `https://senior-jobs-poc-mcp.vercel.app/api/mcp`

MCP는 인증 없이 JSON-RPC POST를 받습니다. 일반 GET이나 SSE 연결은 제공하지 않습니다.

| 도구 | 용도 |
| --- | --- |
| `describe_search_options` | 저장 데이터 기반 선택지·분포·누락 항목 |
| `search_jobs` | 현재 희망조건으로 저장 공고 검색·페이지 조회 |
| `get_job_details` | 선택한 실제 공고 ID의 저장 목록·캐시 상세 요약 |

조회는 저장된 snapshot만 사용하며 AI API나 원천 API를 자동 호출하지 않습니다. 조회 시 KST 접수기간을 다시 판정합니다. 저장 데이터는 전국 전체가 아니며 미기재·미수집·미확인과 조건 불일치를 구분합니다.

## 사용자 흐름

이미 제시한 조건을 유지하고 충분하면 바로 후보를 검색합니다. 고정 질문 순서를 강제하지 않습니다. 공고별 원문 주소가 저장 근거에 있으면 그 주소를 제시하고, 없으면 주소가 없음을 명시하면서 실제 ID의 `get_job_details` 호출 안내와 제목·기관·지역 단서를 제공합니다. 보호된 자체 JSON API를 공식 원문 링크로 표시하거나 ID별 주소를 추정하지 않습니다.

선택 공고의 세부정보가 부족하면 “급여·근무시간·지원조건을 더 찾아드릴까요?”라고 제안합니다. 수락 또는 기존 명시적 요청이 있을 때 호출 클라이언트가 자기 환경의 도구로 요청 항목만 조사합니다. 특정 검색·브라우저·크롤링 서비스는 요구하지 않습니다. 같은 공고인지 확인하고 필드별 원문·출처 URL·조회시각을 제시하며 목록과 원문이 충돌하면 양쪽 값을 보존합니다. 도구가 없거나 접근이 차단되면 미조회로 표시하고 우회하지 않습니다.

## 자동갱신

사용자 요청으로 운영 갱신을 중지했습니다. 예약 Cron은 제거되었고 갱신 시작·비공개 Queue 청크·후속 발행·재시도는 작업 없이 종료합니다. 기존 저장 공고 조회는 유지하며 응답에 `paused_by_request`, `schedulerEnabled: false`를 표시합니다. 자동으로 재개하지 않습니다. 이전 배포의 큐 잔여 실행 확인 범위는 [운영 문서](docs/OPERATIONS.md)를 참고하세요.

기존 대상 ID를 우선 재검증하고 신규 탐색은 별도 커서로 진행합니다. 시간 제한 청크·checkpoint·실패 재개·Private Blob snapshot 게시·비공개 Queue 전달을 사용합니다. 실패 시 이전 snapshot을 유지합니다. 반복 페이지와 미확인 누락 구간을 기록하며 전국 고유 공고 수집 완료를 주장하지 않습니다.

중지 전 Cron은 `/api/refresh`, UTC `0 21 * * *`였습니다. 조회 경로와 달리 갱신 경로는 서버의 기존 `CRON_SECRET` 인증을 계속 요구합니다.

## 실행과 테스트

Node.js 24를 사용합니다.

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm test
```

운영과 같은 소스의 로컬 테스트 132개가 Node 24.21.0에서 통과했습니다. 이 명령은 운영 secret을 내려받거나 원천 전체 수집을 실행하지 않습니다. 배포 설정·운영 범위는 [운영 문서](docs/OPERATIONS.md), 소스 보존 방식은 [Git 이력](docs/HISTORY.md)을 참고하세요.

## 데이터와 비밀 파일

`data/jobs.json`은 기존 운영 코드에 포함된 공개 원천의 부분 표본과 캐시 관찰 요약입니다. 현재 운영 데이터는 Private Blob에서 읽으며 실제 건수·원천 관찰시각·갱신 범위는 MCP 응답에 표시합니다. 전체 상세 원문 문서는 저장하지 않았고 미수집 필드를 임의 보강하지 않습니다.

API 키·토큰·`.env`·Vercel 로컬 상태·운영 Blob 복사본·실행 증거·사용자 화면·개인 세션 파일은 저장소에서 제외합니다. 원천 조회 자격 증명과 Cron secret은 Production 서버에만 유지합니다.
