# Senior jobs MCP

기본 조회와 자동갱신을 하나의 프로젝트로 관리하는 비공개 소스 저장소입니다.

이 초기 리비전은 기존 기본 MCP 1.1.1입니다. 공고 선택지, 저장 공고 검색, 선택한 공고의 캐시 상세를 제공하는 세 가지 읽기 전용 도구를 포함합니다. 검색과 상세 조회는 외부 원천 API를 호출하지 않습니다.

- `describe_search_options`: 저장 데이터의 선택지와 누락 항목
- `search_jobs`: 사용자가 제시한 조건으로 저장 공고 검색
- `get_job_details`: 실제 공고 ID의 저장 목록과 캐시 상세 요약

저장된 데이터는 공개 원천의 부분 표본이며 전국 전체나 실시간 상태를 보장하지 않습니다. 전체 상세 문서와 캐시 관찰 요약을 구분하고, 조회 시 KST 접수기간을 다시 판정합니다.

## 테스트

Node.js 24에서 `npm test`를 실행합니다. 이 기본 버전은 외부 패키지가 필요 없습니다.

## 소스 보존

초기 소스는 `deployments/public-static-poc-mcp-20261012`의 검증 대상 파일에서 가져왔습니다. 기본 버전은 `basic-mcp-v1.1.1` 태그로 보존하고, 자동갱신 버전은 같은 파일 경로와 Git 이력에서 이어 관리합니다. 작업 화면, 운영 Blob 데이터, 실행 증거와 비밀 파일은 포함하지 않습니다.
